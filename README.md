# OPC 一人电商工作台

本机工作台提供八个岗位、项目与 SKU 资料管理、利润核算、指标导入、任务交接、审批和导出。首次启动会生成带有明确标记的示例项目。图片岗位输出提示词。

需要 Node.js 22.13 或更新版本。运行 `npm start` 并打开终端显示的地址。服务监听本机回环地址，默认端口为 4318，可用 `PORT` 指定其他端口。

工作台数据库和附件保存在本机 `.data/`。图像演示素材和 Excel 导入可分别使用带 Pillow 和 openpyxl 的 Python，可通过 `OPC_PYTHON` 指定解释器。运行 `npm test` 验证本地工作流。

可在接入设置中配置本机 Ollama 或兼容模型。第三方服务凭据通过本机环境变量配置，具体字段显示在接入设置。店铺相关写入能力取决于平台授权和已核验的执行回执。
